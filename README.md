# 🔋 Battery Management System (BMS) for Electric Vehicles

## 📌 Project Overview

The **Battery Management System (BMS)** is an Electric Vehicle (EV)-based project designed to improve battery efficiency, safety, and reliability. The system continuously monitors battery health, controls temperature, manages automatic battery switching, and displays real-time battery and charging information.

The project ensures uninterrupted power by using a dual-battery system where one battery powers the vehicle while the other charges. Once the charging battery reaches its full voltage, the system automatically switches the batteries, allowing continuous operation and extending battery life.

---

# 🎯 Objectives

* Monitor battery voltage in real time.
* Automatically control the cooling fan based on battery temperature.
* Prevent battery overheating.
* Automatically switch between two batteries.
* Monitor charging voltage generated by the system.
* Improve battery efficiency and lifespan.
* Increase the safety and reliability of the EV battery system.

# ⚙️ System Workflow

1. The temperature sensor continuously monitors the battery temperature.
2. If the temperature exceeds the predefined limit, the cooling fan automatically turns ON.
3. Battery A powers the EV while Battery B charges using the generated power.
4. The system continuously monitors:

   * Battery A voltage
   * Battery B voltage
   * Charging voltage
5. When the charging battery becomes fully charged, the system automatically switches the batteries:

   * The charged battery powers the system.
   * The previously active battery starts charging.
6. The monitoring process repeats continuously for efficient battery management.

# 🔄 Automatic Battery Switching

### Battery 1 Active

* Battery 1 powers the system.
* Battery 2 charges.
* Once Battery 2 reaches full voltage, the system switches to Battery 2.

### Battery 2 Active

* Battery 2 powers the system.
* Battery 1 charges.
* Once Battery 1 reaches full voltage, the system switches back to Battery 1.

---

# 🌡️ Temperature Control

* The temperature sensor continuously measures battery temperature.
* If the temperature exceeds the predefined threshold:

  * Cooling fan turns ON.
* When the temperature drops below the threshold:

  * Cooling fan turns OFF.

This helps protect the battery from overheating and improves its lifespan.
